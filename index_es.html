Evolución de HTTP

HTTP/1.1 introdujo Keep-Alive por defecto, permitiendo múltiples solicitudes sobre una sola conexión TCP.

Códigos de Estado HTTP

Los códigos de estado se agrupan en cinco categorías, cada una comenzando con un dígito específico (1xx a 5xx).

Categoría Significado Ejemplos Comunes
1xxInformativo101 Switching Protocols
2xxÉxito200 OK, 201 Created, 204 No Content
3xxRedirección301 Moved Permanently, 302 Found
4xxError del Cliente400 Bad Request, 401 Unauthorized, 404 Not Found
5xxError del Servidor500 Internal Server Error, 503 Service Unavailable

Nivel 3: HATEOAS

La hipermedia guía al cliente.

2. Visión General de Go para APIs

¿Por qué Go para Backend?
  • Biblioteca estándar sólida (net/http, encoding/json)
  • Compilación rápida y despliegue de binario único
  • Concurrencia nativa (goroutines y channels)
  • Alto rendimiento para APIs de baja latencia

Teoría de Concurrencia

Goroutines

Hilos ligeros gestionados por el runtime de Go.

go doWork() // Ejecución no bloqueante
Channels

Conductos que conectan goroutines concurrentes para la comunicación.

ch := make(chan int)
go func() { ch <- 42 }()
val := <-ch

Ejemplos de Compilación Cruzada

# Compilar para Linux AMD64 (desde cualquier SO)
GOOS=linux GOARCH=amd64 go build -o server-linux main.go

# Compilar para Windows
GOOS=windows GOARCH=amd64 go build -o server.exe main.go

# Compilar para ARM (Raspberry Pi)
GOOS=linux GOARCH=arm64 go build -o server-arm main.go

3. Fundamentos de net/http

ResponseWriter (w)

Se utiliza para construir la respuesta. Orden: Headers -> Status -> Body.

w.Header().Set("Content-Type", "application/json")
w.WriteHeader(http.StatusCreated)
w.Write([]byte(`{"ok":true}`))
Request (r)

Contiene todos los datos del cliente: Method, URL, Header, Body, PathValue.

id := r.PathValue("id")
q := r.URL.Query().Get("search")
body := r.Body

4.3 Variaciones Base

Ejemplo 4.3.1 - DefaultServeMux con HandleFunc

http.HandleFunc("/", func(w http.ResponseWriter, r *http.Request) {
    w.Write([]byte("Home"))
})
log.Fatal(http.ListenAndServe(":8080", nil))

Ejemplo 4.3.2 - DefaultServeMux con Handle

http.Handle("/", http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
    w.Write([]byte("Home"))
}))
log.Fatal(http.ListenAndServe(":8080", nil))

Ejemplo 4.3.3 - Enrutamiento manual directo

log.Fatal(http.ListenAndServe(":8080",
    http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        switch r.URL.Path {
        case "/": w.Write([]byte("Home"))
        case "/api": w.Write([]byte("API"))
        default: http.NotFound(w, r)
        }
    }),
))

4.4 Ejemplos Prácticos

Ejemplo 4.4.1 - Parámetros de URL (r.URL.Query)

http.HandleFunc("/hello", func(w http.ResponseWriter, r *http.Request) {
    name := r.URL.Query().Get("name")
    fmt.Fprintf(w, "Hello, %s!", name)
})

Ejemplo 4.4.2 - Respuesta JSON

http.HandleFunc("/api/user", func(w http.ResponseWriter, r *http.Request) {
    w.Header().Set("Content-Type", "application/json")
    json.NewEncoder(w).Encode(map[string]string{"name": "John", "role": "Developer"})
})

Ejemplo 4.4.6 - r.PathValue (Go 1.22+)

mux.HandleFunc("GET /users/{id}", func(w http.ResponseWriter, r *http.Request) {
    id := r.PathValue("id")
    fmt.Fprintf(w, `{"id":"%s"}`, id)
})

4.9 Dos Servidores en Puertos Distintos con Goroutines

func main() {
    mainServer := &http.Server{Addr: ":8080", Handler: newMainMux()}
    mockServer := &http.Server{Addr: ":3000", Handler: newMockMux()}

    go func() {
        if err := mainServer.ListenAndServe(); err != nil && err != http.ErrServerClosed {
            log.Fatalf("error: %v", err)
        }
    }()

    log.Fatal(mockServer.ListenAndServe())
}

6. Docker: Construcción y Ejecución

6.1 Dockerfile multi-etapa

FROM golang:1.25.6-alpine AS builder
WORKDIR /src
COPY . .
RUN go build -o /out/server main.go

FROM alpine:3.20
COPY --from=builder /out/server /app/server
USER nobody:nobody
ENTRYPOINT ["/app/server"]

6.2 Comandos Básicos de Docker

Construir Imagen
docker build -t nethttp-server:local .
Ejecutar Contenedor
docker run -d --name nethttp-server -p 8080:8080 nethttp-server:local
Ver Logs
docker logs -f nethttp-server
Detener y Eliminar
docker stop nethttp-server && docker rm nethttp-server
